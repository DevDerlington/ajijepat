PORTFOLIO WEBSITE — QUICK START

1. Extract the ZIP file.
2. Open the extracted folder in Visual Studio Code.
3. Open index.html in your browser, or use the VS Code Live Server extension.
4. Edit the placeholder information in index.html.

IMPORTANT CUSTOMIZATIONS
- Replace "Your Name" and "YN" with your own name and initials.
- Replace hello@example.com with your email address.
- Update the GitHub, LinkedIn and WhatsApp links.
- Replace the profile placeholder in the hero section with your own photo.
- Replace the sample project cards with your real projects.
- Update the skills and biography to reflect your actual experience.

FILES
- index.html  : Website content and sections
- style.css   : Colours, layout, responsive design and styling
- script.js   : Mobile navigation, active menu and current year

The page uses Bootstrap 5.3 via CDN and Google Fonts, so an internet connection is needed for those external resources to load.
